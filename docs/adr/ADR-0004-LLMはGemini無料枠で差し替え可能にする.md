# ADR-0004: LLM は Gemini 無料枠を使い、提供元とモデルは差し替え可能にする

- 状態: 提案（商用利用条件の確認待ち）
- 日付: 2026-10-01
- 関連: REQ-002（BR-002-05, BR-002-09）

## 背景
月額0円が前提。要件2章で Gemini API の無料枠（Flash 系）を使うことが決まっている。
無料枠では入出力が改善に使われうるが、PR案件の情報を含めて送ることは新島infoと合意済み。
ただし、京愛による無償提供でも会社の事業としての利用になるため、無料枠の商用利用条件を確認する必要がある。

## 決定
- `LlmClient` インターフェース（生成: プロンプト＋JSON スキーマ → JSON）を置き、Gemini 実装を1つ作る。
- 提供元・モデル名・日次上限は `tenant_settings` の値で切り替える。
- 呼び出し回数は自前で数え（`llm_usage_daily`）、上限の手前で止める。止まったら手動コピペで続けられるようにする。

## 検討した代替案
- 最初から有料プラン: 投稿量からは少額の見込みだが、月額0円の前提を崩す。抵触が判明した時点で切り替える。

## 結果
- モデルの入れ替わりが早いので、モデル名はコードに書かない。
- 未決: 商用利用条件（要件13章）。抵触する場合は有料プランへ切り替え、この ADR を置き換える。この判断は法務面を含むため **AIの下書き。専門家の確認が必要**。
